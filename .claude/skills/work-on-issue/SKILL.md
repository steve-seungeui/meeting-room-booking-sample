# 이슈 처리 절차

1. GitHub MCP 서버의 도구로 이슈의 본문과 댓글을 읽고, 요구 사항과 완료 조건을 목록으로 정리한다.
2. 코드를 고치기 전에 `impact-investigator` 서브에이전트에게 요구 사항을 전달해 영향 범위를 조사하게 한다.
3. 요구 사항을 확인하는 테스트를 먼저 작성하고, 실행해서 실패하는 것을 확인한다.
4. 구현한 뒤 `npm run typecheck`와 `npm test`를 실행한다.
5. 커밋 메시지의 첫 줄 끝에 `(#이슈 번호)`를 붙여 커밋한다.
6. [report-template.md](report-template.md)의 형식으로 이슈에 남길 작업 보고 초안을 작성한다. 이슈에 직접 댓글을 남기지 않는다.
